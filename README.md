# FORMFORGE

**Maximum taste. Minimum waste.**

FORMFORGE is a portable, zero-dependency AI agent skill for frontend design, engineering, and quality assurance. It combines product-grounded design intelligence, production engineering, purposeful motion, multi-scale critique, evidence-gated verification, and strict code/context economy.

## Capabilities (Phase 05)

- **Operating Kernel** ([SKILL.md](SKILL.md)): Activation boundaries, 5-dimension classification, adaptive modes (`QUICK`, `STANDARD`, `PREMIUM`, `FLAGSHIP`), 10-level priority ladder, and 6-step code economy ladder.
- **Core & Verification Intelligence** (`references/`): [routing-and-modes.md](references/routing-and-modes.md), [implementation-economy.md](references/implementation-economy.md), [project-and-memory.md](references/project-and-memory.md), [verification-and-refinement.md](references/verification-and-refinement.md), [visual-critique.md](references/visual-critique.md), [functional-and-technical-audits.md](references/functional-and-technical-audits.md).
- **Design Intelligence** (`references/`): [creative-direction.md](references/creative-direction.md), [typography-and-content.md](references/typography-and-content.md), [color-and-surfaces.md](references/color-and-surfaces.md), [layout-and-responsive.md](references/layout-and-responsive.md), [ux-and-systems.md](references/ux-and-systems.md), [industry-patterns.md](references/industry-patterns.md).
- **Engineering & Motion Intelligence** (`references/`): [html-css-responsive.md](references/html-css-responsive.md), [components-and-frameworks.md](references/components-and-frameworks.md), [motion-and-interactions.md](references/motion-and-interactions.md), [accessibility-engineering.md](references/accessibility-engineering.md), [performance-and-reliability.md](references/performance-and-reliability.md).
