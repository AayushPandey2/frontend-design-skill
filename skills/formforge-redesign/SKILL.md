# /formforge-redesign

## Purpose & Scope

Reevaluate product requirements and establish a stronger, more coherent creative direction and UX architecture for an existing interface while preserving required functionality and user constraints.

## Activation Criteria & Boundaries

Use when incremental `/formforge-polish` is insufficient because layout structure, navigation, or visual identity needs a fundamental rethink. Do not auto-chain or circularly invoke sibling skills; suggest optional next skills only after completing this workflow.

## Workflow

1. Audit the existing interface's functional requirements, user constraints, and core weaknesses.
2. Establish a stronger creative direction (`creative-direction.md`) and UX structure (`ux-and-systems.md`) without breaking required flows.
3. Implement the redesigned layout, typography, surface system, and components cleanly.
4. Verify all preserved functionality, responsive breakpoints, accessibility, and visual craft.

Redesigned interface with preserved core functionality, documented rationale, and verified functional/visual checks.
