# Industry-Specific Design Patterns

**Load when**: Calibrating density, trust signals, navigation, or hierarchy for a specific product domain.

| Domain | Primary Priorities | Density & Hierarchy | Avoid |
| :--- | :--- | :--- | :--- |
| **Marketing / Landing** | Positioning, primary CTA, storytelling, trust | Spacious–balanced; one focal hero | Cloned card-kits, fake testimonials |
| **SaaS Apps** | Task efficiency, predictable nav, clear state | Balanced–compact; scannable actions | Marketing fluff in operational flows |
| **Dashboards** | Data comprehension, labels, scan speed | Compact–dense; KPI -> breakdown | Decorative charts, invented metrics |
| **E-Commerce** | Product framing, transparent pricing, checkout | Balanced; media + variant/price | Fake urgency, hidden fees, cramped mobile |
| **Financial** | Accuracy, trust, `tabular-nums`, error prevention | Compact; high legibility, clear deltas | Effects obscuring figures, color-only status |
| **Developer Tools** | Density, keyboard efficiency, code legibility | Compact–dense; monospace clarity | Excessive whitespace, mouse-only flows |
| **AI Apps** | Prompt input, stop/retry, readable output, citations | Balanced; workspace + provenance | Implying fake AI, raw unescaped output |
| **Portfolios** | Distinct identity, expressive type, work showcase | Spacious/editorial; work first | Spectacle hiding actual projects |
| **Luxury / Premium** | Restraint, materiality, framing, pacing | Spacious; quiet chrome | Cliché black-and-gold defaults |
| **Education / Productivity** | Comprehension, progression, focus, feedback | Balanced; clear step/progress cues | Multi-panel clutter during active tasks |
