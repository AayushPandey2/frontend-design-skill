# Industry-Specific Design Patterns

**Load when**: Designing for a specific product domain and calibrating density, trust signals, navigation, or hierarchy. Do not duplicate shared typography, color, or accessibility rules here.

| Product Domain | Primary Priorities | Density & Hierarchy | Key Pitfalls to Avoid |
| :--- | :--- | :--- | :--- |
| **Marketing / Landing** | Clear positioning, primary CTA, storytelling, trust, visual rhythm | Spacious to balanced; one focal hero | Generic hero card-kits, fabricated testimonials |
| **SaaS Applications** | Task efficiency, predictable nav, clear system state | Balanced to compact; scannable actions | Marketing decoration inside operational workflows |
| **Dashboards / Analytics** | Data comprehension, accurate labels, scan speed, clear charts | Compact to dense; KPI -> breakdown | Decorative charts, invented metrics, low-contrast gridlines |
| **E-Commerce** | Product presentation, transparent pricing, filtering, smooth checkout | Balanced; imagery + clear variant/price | Fake urgency timers, hidden fees, cramped mobile checkout |
| **Financial Products** | Accuracy, trust, `tabular-nums` alignment, error prevention | Compact; high legibility, clear deltas | Visual effects obscuring figures, ambiguous status colors |
| **Developer Tools** | Information density, keyboard efficiency, technical readability | Compact to dense; monospace/code clarity | Excessive whitespace, mouse-only workflows |
| **AI Applications** | Clear prompt input, streaming/stop/retry, readable output, provenance | Balanced; workspace + citation clarity | Implying unavailable AI capabilities, raw unescaped output |
| **Creative Portfolios** | Distinct identity, expressive type, project showcase, restrained motion | Spacious/editorial; work front-and-center | Spectacle that hides or delays access to actual projects |
| **Luxury / Premium** | Visual restraint, materiality, photography/framing, deliberate pacing | Spacious; quiet chrome | Cliché black-and-gold defaults without brand substance |
| **Education / Productivity** | Comprehension, progression, clear feedback, distraction-free focus | Balanced; clear step/progress cues | Overwhelming multi-panel clutter during active learning |
